News Injections:
Different Events are introduced to the system as Events 

class Event:
    tick: int
    kind: str           # earnings, macro, regulatory, product, rumour, leak
    ticker: int         # sector
    true_impact: float  # change in fundamental value; hidden from agents (0 for a false rumour)
    sentiment: float    # how it's presented, -1..1
    credibility: float  # trustworthiness
    salience: float     # how attention-grabbing it is
    complexity: float   # knowledge needed to interpret it correctly
    seeding: str        # official, outlet, influencer, insider, anonymous
    parent: int = -1    # for follow-ups: confirmations, denials, corrections

Platform Diffusion:
How far information travels in one cycle is determined by the nature of the event and randomness.
Belief and Narrative Update:
Belief - an item only moves Confidence if it is close enough to the current view. Size of the move depends on impulsiveness, knowledge and item credibility
Adopt - agent takes on a narrative seen in its feed
Mutate - agent changes it when passing it on (more extreme, less credible), more likely for impulsive, low knowledge agents
Invent - after a big price move with no explanation, agent makes one up in the direction of the move
Trading Decisions:
Only investors trade, and only when online
expected return = fundamentalist part (perceived value vs price) + chartist part (momentum) + sentiment part (Confidence) —- weighted average based on category
target position = risk tolerance x wealth x expected return / risk
order = target - current holding, only if bigger than a threshold (lower for impulsive agents)
Market participant category sets the mix and holding period; the mix shifts toward whatever has been profitable lately
Simple orderbook!!!
Market Maker:
All orders summed into net demand D
new price = price x exp(λ x D / liquidity + noise)
Only clears during trading hours
Predetermined values – mostly a blackbox, predetermined parameters from pretraining
